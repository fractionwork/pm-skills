# pm-skills

Public distribution of **pm-kit** — Claude Code skills for project-board management with
Fraction hygiene applied at the moment a card is written.

```
/plugin marketplace add fractionwork/pm-skills
/plugin install pm-kit@pm-skills
```

Then restart Claude Code and run `/pm-setup` once. No git credentials, SSH key or
`gh auth login` needed — Claude Code falls back to anonymous HTTPS for a public repo.

Full documentation: `plugins/pm-kit/README.md` and `plugins/pm-kit/docs/getting-started.md`.

on every change to the kit, and direct edits here are overwritten. Open issues and PRs
against the source repo.
