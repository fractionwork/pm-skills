# backlog.md format

Standard format for local backlogs when no PM system is connected. Generated by `bootstrap` (fallback), read by `next-task`, updated by `card-done`.

## Structure

```markdown
# [Project Name] Backlog

## E1: Auth + User Management [P0]
> sign-up, sign-in, session handling, route protection

### [E1-S1] Sign up flow (3 SP) @austin — TODO
- [ ] Email validation
- [ ] Password strength check
- [ ] Submit creates user + org

### [E1-S2] Sign in flow (2 SP) @austin — DONE
- [x] Email/password login
- [x] Session cookie

### [E1-S3] Password reset (2 SP) @unassigned — TODO
- [ ] Reset email via BullMQ
- [ ] Token validation

## E2: Core Workflow [P1]
> the main thing the product does

### [E2-S1] Create product (5 SP) @unassigned — TODO
- [ ] Server Action with Zod validation
- [ ] Form with useActionState
- [ ] Integration test

## v2 (deferred)
- Analytics dashboard
- AI recommendations
```

## Conventions

### Epics
`## E[N]: Name [P0-P3]`
- `E[N]` — epic number, sequential
- `[P0-P3]` — priority (P0 = critical, P3 = low)
- Blockquote line beneath: one-line scope summary

### Stories (work units)
`### [EX-SY] Title (N SP) @assignee — STATUS`
- `[EX-SY]` — epic + story ID (E1-S1, E2-S3, etc.)
- `(N SP)` — story points
- `@assignee` — username or `@unassigned`
- `STATUS` — one of: `BACKLOG`, `TODO`, `WIP`, `REVIEW`, `TESTING`, `DONE`

Bullets beneath are acceptance criteria:
- `- [ ]` unchecked = not done
- `- [x]` checked = done

### Deferred
`## v2 (deferred)` section at the bottom. Plain bullets, not stories.

## Parsing rules (for next-task)

1. Stories (`### [E`) are the work units — not bullets, not epics
2. Filter: skip DONE, REVIEW, TESTING stories. Pick from TODO first; only fall back to BACKLOG if TODO is empty (warn builder).
3. Priority: inherit from epic `[P0-P3]` heading
4. Sort: assigned-to-me first → P0 before P1 → smallest SP first → epic order
5. If no `### [E` headings exist, fall back to flat `- [ ]` bullets (legacy format)

## Updating (for card-done)

When a story is completed:
- Change `— TODO` or `— WIP` to `— DONE`
- Check all acceptance criteria: `- [ ]` → `- [x]`

When starting a story (next-task):
- Change `— TODO` to `— WIP`
- Change `@unassigned` to `@[builder]`

## Legacy format (flat bullets)

If the project predates the heading format:
```markdown
- [ ] E1-S1: Sign up flow (3 SP) @unassigned
- [x] E1-S2: Sign in flow (2 SP) @jeremy — done
```

`next-task` auto-detects: if any `### [E` headings exist, use heading format. Otherwise fall back to flat bullets.
