# Dependencies for the first-party Asana MCP server (scripts/asana_mcp.py).
# Install with: pip install -r scripts/requirements-mcp.txt
#
# asana_ops.py (reused for auth + REST) also needs `requests`.
# asana_mcp.py supports both SDK majors: 1.x's mcp.server.fastmcp.FastMCP and
# 2.x's mcp.server.MCPServer. Both are verified to complete a stdio handshake and
# serve the same 12 tools, so a venv does not have to move in lockstep with the
# plugin.
#
# The upper bound stays, and is load-bearing rather than caution. 2.0 removed
# mcp.server.fastmcp outright with no deprecation, and because a server that dies
# during the handshake registers nothing, the only symptom was the Asana tools
# silently not existing — no error, anywhere. `pip install --upgrade` with no
# ceiling is what let that reach working machines. Raising this to <4 means
# checking 3.x against the same handshake test first.
mcp>=1.2.0,<3
requests>=2.31.0
